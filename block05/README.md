# Блок 05: облачные модели (клиент к API)

## Практическое задание

### Ресурсы

После создания окружения вам будет выдан временный GitLab репозиторий на gitlab.rebrainme.com. Если учётной записи у вас не было — она будет создана. Если была — вы сможете использовать ваш пароль для входа. Если вы его забыли — вы можете восстановить его по своему email на gitlab.rebrainme.com.

Помимо этого, вам будет предоставлен ключ доступа к **llm.rebrainme.study**, который позволит отправлять запросы к API облачных моделей (Gemini).

### Задача

Вам необходимо написать простой скрипт на Python, который будет принимать пользовательский промпт из командной строки, отправлять запрос к облачной LLM и выводить ответ на экран. Скрипт необходимо залить в предоставленный Git репозиторий.

### Критерии успешного выполнения

- Скрипт в репозитории должен лежать в корне в ветке **main** и называться **`client.py`**.
- Скрипт должен использовать клиент **openai** (OpenAI Python Client).
- Скрипт не должен содержать API-ключ в открытом виде. Он должен читать API-ключ из переменной окружения **`OPENAI_API_KEY`**.
- Клиент должен использовать сервер API: **`https://llm.rebrainme.study`** (в тексте задания на платформе иногда встречается опечатка вида `rebrianme.study` — ориентируйтесь на выданный вам эндпоинт и инструкцию курса).
- Скрипт должен принимать текстовый промпт в качестве аргумента командной строки (используйте `sys.argv` или `argparse`).
- Клиент должен отправлять запрос **ChatCompletion** к модели **`gemini-2.5-flash`**.
- Скрипт должен выводить в **STDOUT** только текст ответа модели (поле `content` из ответа), без лишних кавычек, JSON-обёрток или служебной информации.

Курс на платформе REBRAIN: [Облачные модели](https://my.rebrainme.com/course/llm/task/3146).

## Описание решения в этой папке

### Сдача в GitLab: `user-repo-vaemy/client.py`

Файл **`user-repo-vaemy/client.py`** — эталон для требований задания:

- **`argparse`**: позиционный аргумент `prompt` с описанием.
- **`OpenAI`** из пакета `openai` с **`base_url="https://llm.rebrainme.study"`** и **`api_key`** из **`os.getenv("OPENAI_API_KEY")`** (ключ в коде не захардкожен).
- Опционально **`python-dotenv`** (`load_dotenv()`): удобно подхватывать `OPENAI_API_KEY` из файла `.env` локально; в репозитории для сдачи `.env` не коммитят (см. **`user-repo-vaemy/.gitignore`**).
- Вызов **`client.chat.completions.create`** с моделью **`gemini-2.5-flash`** и одним сообщением пользователя с текстом промпта.
- В stdout выводится только **`response.choices[0].message.content`**; при отсутствии ключа сообщение об ошибке уходит в **stderr**, процесс завершается с ненулевым кодом.

Пример запуска после установки зависимостей и экспорта ключа:

```bash
export OPENAI_API_KEY="ваш_ключ"
python client.py "Кратко: что такое LLM?"
```

Зависимости: `openai`, для локального `.env` — `python-dotenv` (`pip install openai python-dotenv`).

| **`main.py`** | Тот же паттерн **OpenAI SDK** + **`llm.rebrainme.study`**, фиксированный диалог (system + user), вывод с поясняющими строками — черновик/демо, не формат сдачи `client.py`. |
