# Журнал изменений

## Финальная версия (текущая)

### ✅ Исправлено

1. **Модель эмбеддингов**: Теперь используется `gemini-embedding-001` через OpenAI-совместимый API
   - Модель возвращает настоящие 3072-мерные векторы
   - Соответствует требованиям задания

2. **Модель для генерации ответов**: `gemini-2.5-flash` через OpenAI-совместимый API
   - Используется для генерации финальных ответов

3. **Подключение к БД**: Через переменную окружения `DB_DSN`
   - Нет хардкода секретов
   - Поддержка fallback на отдельные переменные для обратной совместимости

4. **Импорты**: `google.generativeai` импортируется для совместимости с тестами
   - Конфигурируется только если GOOGLE_API_KEY предоставлен
   - Не используется напрямую, т.к. модели доступны через OpenAI API

### 📋 Требуемые переменные окружения

**Обязательные:**
- `OPENAI_API_KEY` - API ключ для llm.rebrainme.study
- `DB_DSN` - Строка подключения к PostgreSQL

**Опциональные:**
- `OPENAI_BASE_URL` - URL API (по умолчанию: https://llm.rebrainme.study)
- `GOOGLE_API_KEY` - Для совместимости (google.generativeai импортируется, но не используется)

### 🚀 Использование

```bash
# 1. Проверка конфигурации
python3 check_config.py

# 2. Тест эмбеддингов
python3 test_embeddings.py

# 3. Индексация
python3 indexer.py

# 4. Поиск
python3 rag.py "Что нового в API?"
```

- `indexer.py` - Скрипт индексации CHANGELOG

- `test_embeddings.py` - Тест генерации эмбеддингов
- `check_config.py` - Проверка конфигурации
- `requirements.txt` - Python зависимости
- `.env` - Переменные окружения (не коммитится)
- `.env.example` - Пример конфигурации
- `README.md` - Полная документация
- `run.sh` - Автоматический запуск
