# Блок 04: локальный сервер инференса (llama.cpp, server)

## Практическое задание

### Ресурсы

Вам предоставлена виртуальная машина с операционной системой Ubuntu 24.04.

- **Железо:** CPU-only конфигурация (без видеокарты).

### Задача

Необходимо развернуть локальный сервер инференса LLM, используя инструмент **llama.cpp** в режиме **server**.

### Критерии успешного выполнения

- **[Сетевая активность]:** порт **8080** (TCP) прослушивается процессом **llama-server**.
- **[Модели]:** в выводе команды `curl http://localhost:8080/v1/models` присутствует модель **`Qwen2.5-7B-Instruct-Q4_K_M.gguf`**.

---

## Описание решения в этой папке

### Запуск сервера

Скрипт **`llama-server-Qwen2.5-7B-Instruct-Q4_K_M.sh`** задаёт типичный сценарий для задания:

1. **`sudo systemctl stop ollama`** — останавливает сервис Ollama, если он занимает ресурсы или порт (если Ollama не установлена, шаг можно пропустить или закомментировать).
2. Запуск **`llama-server`** с моделью в формате GGUF через Hugging Face Hub:
   - репозиторий **`bartowski/Qwen2.5-7B-Instruct-GGUF`**, квантизация **`Q4_K_M`** (флаг **`-hf`** подтягивает нужный `.gguf`);
   - **`-ub 2048`**, **`-b 2048`** — размеры батча для CPU-инференса;
   - **`-c 15000`** — размер контекста;
   - **`--jinja`** — шаблоны чата в стиле Jinja (удобно для Instruct-моделей);
   - **`--host 0.0.0.0`**, **`--port 8080`** — слушать на всех интерфейсах и порту, который проверяется в критериях.

Перед запуском на ВМ должны быть собраны/установлены бинарники **llama.cpp** с целью **`server`** (команда **`llama-server`** доступна в `PATH`). Первый запуск с **`-hf`** может занять время из‑за загрузки весов.

### Проверка критерия «модели»

Скрипт **`check_models.sh`** выполняет GET-запрос к **`http://localhost:8080/v1/models`** и проверяет, что в ответе (JSON) встречается строка **`Qwen2.5-7B-Instruct-Q4_K_M.gguf`**. Переменная **`API_KEY`** оставлена пустой для сервера без авторизации; если вы включите API-ключ на стороне llama-server, задайте тот же токен в **`API_KEY`** в скрипте.

Запуск (после старта **llama-server**):

```bash
chmod +x check_models.sh
./check_models.sh
```

Для проверки порта вручную:

```bash
ss -tuln | grep 8080
# или
sudo lsof -iTCP:8080 -sTCP:LISTEN
```

Убедитесь, что в списке процессов слушателя фигурирует **llama-server** (критерий задания).
