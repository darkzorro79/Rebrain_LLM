# Блок 8: безопасность и этика LLM — защита и «галлюцинации»

## Практическое задание

### Описание

Ваша задача — реализовать механизм двухэтапной обработки запроса. Первый этап — это «модель-инспектор», которая оценивает входящий запрос на наличие признаков атаки (Prompt Injection, Jailbreak). Если запрос признан опасным, выполнение прерывается. Если безопасным — запрос передаётся основной модели.

### Ресурсы

- **API URL:** `https://llm.rebrainme.study`
- **API Key:** берётся из переменной окружения `REBRAIN_API_KEY`
- **Модель-инспектор:** `gemini-2.5-flash` (быстрая и строгая)
- **Основная модель:** `gemini-3-flash-preview`

### Алгоритм скрипта

Напишите скрипт `guardrail.py`, который:

1. Принимает текст запроса как аргумент командной строки (используйте `sys.argv` или `argparse`).
2. **Этап 1: проверка безопасности.**
   - Отправляет запрос на модель `gemini-2.5-flash`.
   - Использует **Structured Output** для получения вердикта:

```json
{
  "score": "float (0.0 - 10.0, где 10 - явная атака)",
  "verdict": "string (SAFE | UNSAFE)",
  "comment": "string (краткое обоснование)"
}
```

3. **Логика фильтрации:** если `score >= 8.0`, скрипт должен вывести сообщение об ошибке (содержащее слово **"ATTACK"**) и прекратить работу.
4. **Этап 2: выполнение.** Если проверка пройдена, запрос отправляется на основную модель `gemini-3-flash-preview`. Результат основной модели выводится на экран.

### Критерии проверки

- Использование `response_format` с `json_schema` для модели-инспектора.
- Использование двух разных моделей для разных этапов.
- Корректная обработка порога `score` (8.0).
- Отсутствие захардкоженного API-ключа.

## Решение в этом репозитории

В каталоге есть скрипт `guardrail.py`, реализующий описанный пайплайн.

### Что сделано в `guardrail.py`

- Клиент **OpenAI-compatible** к `https://llm.rebrainme.study`, ключ только из `REBRAIN_API_KEY`.
- **Этап 1:** модель `gemini-2.5-flash`, ответ в формате `response_format` с `type: json_schema` и схемой полей `score`, `verdict`, `comment`; разбор через `pydantic`-модель `SecurityResult`.
- **Порог:** при `score >= 8.0` (или вердикте `UNSAFE`) выводится сообщение с текстом **ATTACK**, процесс завершается с ненулевым кодом.
- **Этап 2:** для прошедших проверку запросов вызывается `gemini-3-flash-preview`, ответ печатается в консоль.
- Дополнительно в репозитории есть варианты под локальные модели (`guardrail_ollama.py`, `guardrail_ollama_qwen-next-coder.py`, `sg.py`, `sg_ollama.py`) — они не входят в формулировку задания на платформе REBRAIN.

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка

```bash
export REBRAIN_API_KEY="your_api_key_here"
```

### Запуск

```bash
python guardrail.py Ваш текст запроса в одной или нескольких аргументах
```

Пример:

```bash
python guardrail.py Объясни, что такое рекурсия
```

Скрипт выводит этап инспекции (оценка, вердикт, комментарий), при успехе — ответ основной модели.
